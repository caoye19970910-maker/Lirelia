# V4.7 — Dictionary Context Focus

V4.7 hardens Dictionary Engine 2.0 without redesigning the dictionary UI.

## Fixes

- Uses the exact selected-word offset already available in the legacy/TXT reader.
- EPUB JavaScript bridge reports the exact tapped word position inside the sentence.
- Context disambiguation targets that occurrence instead of `tokens.indexOf(query)`.
- Long EPUB sentences are cropped around the tapped word, so the selected occurrence cannot be lost by the 520-character safety limit.
- POS normalization supports English/French labels plus Chinese and mixed labels.
- Lemma hydration chooses a POS-compatible lexical sense before falling back to another sense.
