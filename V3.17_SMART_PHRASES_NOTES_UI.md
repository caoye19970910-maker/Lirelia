# V3.17 Smart Phrases & Reading Notes

## 1. Automatic phrase detection

When a reader taps a French word, Language Reader now builds short 2–5-token candidates around the selected position and checks them against the bundled offline dictionary. Only real local dictionary hits are surfaced. Common French elision is normalized for fixed-expression lookup, e.g. `tandis qu’il` can surface `tandis que`. Each detected phrase displays its Chinese meaning and can be opened directly in the same dictionary sheet.

## 2. Reading notes library

The annotation manager now treats highlights and underline as one reviewable reading-note system. It supports book filtering, color/underline filtering, search, Markdown/CSV export, jump-to-source, delete, and direct note editing. Underline remains local-only and does not enter the vocabulary bank.

## 3. Dictionary-card UI

- Removed the duplicate header replay button.
- Kept a single `🔊 发音` action.
- Replaced the old `认识` action with `⌫ 清除`.
- Nouns show `阳性` / `阴性` where resolvable. Heuristic suffix inference is explicitly labeled as `词尾推测` instead of being presented as certain dictionary metadata.
- Existing Chinese meanings for related expressions and word-family items remain visible.

## 4. Reader chrome

The bottom progress/footer overlay has been removed. When controls are summoned, only a compact top strip appears: back, book panel, `Aa`, bookmark, and reading statistics. The book title is not repeated in the chrome. Theme and page/scroll controls remain in the `Aa` reader settings panel.

## Build note

The bundle does not include `gradle-wrapper.jar`, so a full Android/Compose build cannot be executed in this environment. Source syntax was checked with the Kotlin compiler up to dependency resolution, delimiter balance was checked, and the final ZIP is integrity-tested.
