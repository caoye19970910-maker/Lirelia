# V4.5 Translation Experience

This pass was driven by real emulator screenshots after V4.4 successfully launched.

### Quick card
The first visual layer is now lexical: word → lemma/POS/IPA → concise meanings. Sentence translation is a distinct `本句` section below it. An offline word-by-word gloss is never presented as a natural translation.

### Missing dictionary entries
If the bundled/WikDict layers have no definition and network use is allowed, Lirelia requests a translation for the tapped word separately from the sentence. This is especially important for common gaps such as `voyage`.

### Pronunciation
`AUTO` is the new default route for fresh/legacy-default installs. It prioritizes cached audio and a usable Android French voice, then Mainland-friendly web sources, and only uses Google network audio as a final fallback. Successful/connecting pronunciation toasts were removed from the normal reading flow.

### Reading density
Only untouched defaults are migrated: page margin 16dp-equivalent and line spacing 142%. User-customized typography is preserved.
