## WikDict French-Chinese dictionary (optional download)

Lirelia can optionally download WikDict's official French→Chinese SQLite dictionary from `download.wikdict.com`. WikDict is generated from Wiktionary/DBnary data. The downloaded database is not bundled in the APK and is installed only when the user chooses Install/Update in Dictionary Center. The application keeps the attribution visible in the dictionary source label.

Project/generator: https://github.com/karlb/wikdict-gen
Download source: https://download.wikdict.com/dictionaries/sqlite/2/fr-zh.sqlite3
