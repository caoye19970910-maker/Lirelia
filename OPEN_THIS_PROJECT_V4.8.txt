本版重点：
1. 修复 EPUB 滚屏到章节末尾后无法继续的问题。
2. 阅读辅助右侧可直接拖动位置（⋮）和调整大小（↕）。
3. 标注颜色加深。
4. 选词后可取消标注、直接加入生词本、清除该词。
5. 已标单词后续再次出现会继续显示对应颜色；清除后同步消失。

建议实机优先测试：
- 阅读排版 -> 滚屏 -> 连续向下滚到章节末尾，再继续上滑。
- 开启阅读辅助，拖动 ⋮ 和 ↕。
- 长按一个法语单词 -> 选黄色/绿色 -> 看后文同词是否同步着色。
- 再次长按该词 -> 取消标注 / 清除该词。
- 点击查词卡 -> 检查 ✓ 生词 与 清除。
