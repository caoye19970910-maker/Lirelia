# V3.14 Reading Polish

## 1. Publication typography

Normal prose paragraphs use a modest first-line indent while chapter starts and dialogue lines stay flush-left. Paragraph gaps were reduced so the page reads more like a printed book. French punctuation receives same-length non-breaking spaces so punctuation does not get stranded at the start of a new line while text-selection offsets remain stable.

## 2. Reliable reading position

The book repository now persists `reader_position_<bookId>` with a paragraph index and normalized paragraph fingerprint. On reopen it verifies the stored paragraph, searches nearby if the source text shifted, and falls back to legacy progress when needed. Page-mode repagination follows the stable paragraph anchor after typography/orientation changes.

## 3. Unified in-book panel

The previous separate navigation/search sheets are consolidated into one panel with four tabs:

- 目录
- 搜索
- 书签
- 标注

Each result can jump back to its source paragraph.
