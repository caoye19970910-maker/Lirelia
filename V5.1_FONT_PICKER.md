# Lirelia Mobile V5.1 — Font Picker

V5.1 adds a compact font chooser to the EPUB `Aa` reading panel without turning the typography panel into a grid of font buttons.

## Interaction

- `Aa` shows one row: `字体  当前字体  ›`.
- Tapping the row opens a simple selection list.
- The current font is marked with `✓`.
- Selecting an item applies it immediately and closes the picker.
- The selected font family is persisted in `AppSettings` and restored next time.
- There are no font categories or grouped sections.

## Font choices

1. 原书字体 — preserve the EPUB author's font
2. 书籍衬线 — generic serif
3. 清爽无衬线 — generic sans-serif
4. 手写体 — generic cursive
5. 等宽字体 — generic monospace
6. OpenDyslexic
7. Accessible DfA
8. iA Writer Duospace

The last three are accessibility-oriented families already provided by the Readium rendering stack. No additional external font binaries are bundled in this pass.

## Readium integration

- `reader_font_family` is stored alongside existing reader typography preferences.
- `EpubPreferences.fontFamily` receives the selected family.
- Font changes participate in the same re-render/re-highlight lifecycle as size, line spacing and margins so word taps and repeated-word highlighting are restored after typography changes.
