# V5.4 — Sentence Context Engine

## What changed

- EPUB sentence extraction no longer trusts `div` or `p` layout boundaries as sentence boundaries.
- EPUB DOM text is flattened in reading order and every hard wrap/tab/run of whitespace is normalized to a logical space before segmentation.
- The tapped text-node offset is mapped while normalization happens, so repeated words do not shift context to the wrong occurrence.
- `Intl.Segmenter('fr')` remains the primary EPUB segmenter, with a second validation layer for common French abbreviations and initials.
- TXT/PDF sentence segmentation replaces visual line breaks with same-length spaces before `BreakIterator`, preserving offsets while avoiding fake line-wrap sentences.
- TXT/PDF context windows are aligned to 1000 characters.
- EPUB keeps complete sentences up to 2000 characters, with an emergency cap only for malformed punctuation-free chapters.

## Regression case

For the reported passage, tapping any of these:

- `remporté`
- `d’éloquence`
- `condisciples`

must resolve to the same complete sentence:

`Nicolas a remporté le prix d’éloquence, qui récompense chez lui la quantité, sinon la qualité, et il a quitté ses condisciples qui ont nom : Alceste, Rufus, Eudes, Geoffroy, Maixent, Joachim, Clotaire et Agnan.`

Changing font size, line spacing, screen orientation, or pagination must not change the extracted sentence.
