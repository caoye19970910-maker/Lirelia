# Lirelia V4.1 — Readium + Hybrid French→Chinese Dictionary

## Dictionary architecture

1. **Bundled Lirelia dictionary (156k entries)** — primary lexical source for POS, IPA, inflection resolution, examples, related words and phrases.
2. **Official WikDict fr→zh SQLite (optional, ~3 MB)** — merged into the same card to add Wiktionary/DBnary Chinese translations; also provides fallback coverage when the bundled dictionary misses.
3. **Core fallback dictionary** — tiny always-available safety net.

The order is deliberate: WikDict does not replace Lirelia's richer lexical metadata, and Lirelia no longer treats it as a separate encyclopedia-only fallback.

## Installation

Dictionary Center → **WikDict 法中词典** → Install/Update.

The app downloads the official rolling database, verifies the `simple_translation` table and a minimum entry count, and only then atomically replaces the previous copy. A dated 2026-06 URL is retained as a fallback mirror.

## Lookup behavior

- Exact bundled entry + WikDict hit → meanings merged, duplicates removed.
- Bundled miss + WikDict hit → WikDict result shown.
- Inflected forms try `FrenchConjugator.lemmaForForm`, elision cleanup and conservative morphology candidates before WikDict lookup.
- Existing phrases/examples/IPA remain from Lirelia and are never overwritten by WikDict.

## Reader

V4.1 keeps V4.0's Readium EPUB route and translation-first overlay architecture. PDF and text reading paths are unchanged.
