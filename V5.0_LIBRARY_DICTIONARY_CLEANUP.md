# Lirelia Mobile V5.0 — Library & Dictionary Cleanup

V5.0 reorganizes the home experience around the bookshelf and tightens the EPUB magnifier and dictionary presentation based on real emulator/device feedback.

## Library home

- Removed the old Lirelia/Moon promotional header, the large import block, Continue Reading card, and Today Learning card from the library home.
- The home screen now starts with `我的书架`.
- `＋ 导入` and the grid/list switch live together in the top-right action area.
- Search remains directly above the bookshelf.
- User-renamed titles participate in bookshelf search.

## Per-book management

The `•••` menu now keeps the core book actions together in this order:

1. 收藏 / 取消收藏
2. 重命名
3. 隐藏封面 / 显示封面
4. 整理书籍
5. 删除

Rename and cover-visibility preferences are stored as library metadata and are cleared with the removed book. Opening TXT/PDF from the shelf uses the display title; Readium also reads the display title for EPUB chrome and new vocabulary source labels.

## Training

- `今日学习` moved from the bookshelf to the top of the Training hub.
- It shows today's reading time, reading goal, reviewed-word count, vocabulary goal, and current reading streak.

## EPUB reading magnifier

- Magnifier width range is now 65–100%.
- The previous 90% untouched default migrates to 98% once.
- The lens gets extra horizontal safety width and a smaller corner radius to reduce clipped first/last glyphs on high-density emulators.
- Position, height, width and zoom remain controlled in `Aa`.

## Dictionary presentation

- Main noun entries now show gender in the meta line, for example `名词（阳性）` or `名词（阴性）`.
- Inflected plural forms display the lemma and localized morphology (`复数`) before POS/gender.
- Readium and the regular dictionary share the same noun-gender resolver.
- Fixed expressions now show a Chinese gloss underneath the French expression.
- Phrase glossing prefers exact offline phrase entries, then a conservative offline literal noun-complement gloss, and finally the existing network translation fallback when allowed.
- Example sentences remain clean text; IPA is shown only in the headword/meta area, not added to example rows.

## Example cleanup

- Dictionary examples are normalized for display: inline `/IPA/` fragments are removed from example rows.
- Bilingual source examples are split into a French line and a smaller Chinese translation line instead of exposing raw `—` / slash-packed source text.
