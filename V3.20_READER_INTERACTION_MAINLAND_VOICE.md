# V3.20 Reader Interaction & Mainland Voice

## Mainland pronunciation

The previous MAINLAND route depended on a non-Google Android TTS engine already installed on the device. V3.20 changes the route to:

`persistent cache → Youdao French web pronunciation → Baidu French web fallback → Android French TTS`

The first two online candidates use short connection/read timeouts so a failed provider does not block reading for several seconds. Google is never attempted while MAINLAND is selected; switching to Google remains a separate manual network mode.

## Long-press toolbar

The old large analysis/annotation bottom sheet was removed from the long-press path. Long-press now opens a compact floating toolbar with five primary actions: Copy, Highlight, Note, Dictionary, More. More exposes sentence highlight, underline and remove-highlight actions. Text-reading mode also paints the long-pressed word with a temporary blue selection highlight while the toolbar is open.

## Sentence translation card

`阅读整句` is placed directly on the right side of the `整句翻译` heading. The offline dictionary contributes a compact sentence glossary of useful words, even when network translation is unavailable. This glossary is labelled as lexical assistance rather than full-sentence translation.

## Vocabulary review UI

Vocabulary Center review now uses a dedicated card rather than AlertDialog. It shows session progress, item mastery, a large word card, audio, answer reveal, saved context/book source, and three ratings: Forgotten / Familiar / Mastered. Forgotten/Familiar ratings update the adaptive personal-vocabulary scheduler and synchronize the next due time back to the vocabulary table.

### Provider note

The Youdao/Baidu candidates above are website pronunciation endpoints used by their consumer services, not stable public developer APIs. They are therefore isolated behind the manual MAINLAND route, short timeouts, diagnostics and local caching. If a provider changes its web endpoint later, Language Reader can replace that candidate without changing the reader UI or vocabulary data.
