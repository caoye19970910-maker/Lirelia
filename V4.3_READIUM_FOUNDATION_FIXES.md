# V4.3 Readium Foundation Fixes

This maintenance release addresses the V4.2 audit findings.

1. Readium is the EPUB import authority; legacy EPUB extraction is best-effort only.
2. Locator persistence is debounced to reduce write churn during scrolling and auto-scroll.
3. Latest locator is flushed on reader disposal.
4. Bookmark and legacy annotation migration flags are written only after successful completion; unresolved rows remain retryable.
5. V4.1 highlight migration is explicitly executed on `Dispatchers.IO`.
6. Selection toolbar polls Readium's current selection while active so its bounds do not remain stale.
7. Contents panel adds an EPUB annotation tab with Locator jump and delete.
8. WikDict interrupted-swap recovery restores `.previous` when the active DB is missing.
9. Volume-key setting uses Compose state for immediate switch feedback.
10. `usesCleartextTraffic` was removed.
11. Ollama remains removed (only stale preference cleanup remains for upgrades).
