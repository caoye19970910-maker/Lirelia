# V4.6 — Dictionary Engine 2.0

This release separates **lexical meanings** from **inflection analyses** instead of treating every stored line as a dictionary definition.

## What changed

- Added a normalized offline lexical database: `lirelia_lexical_engine_v2.db`.
- 29k+ semantic lexeme rows and 172k+ normalized form analyses are separated into different tables.
- `tâche` can now be both:
  - `tâche` — noun, “工作 / 任务”
  - `tâcher` — verb inflection, shown as a grammatical analysis rather than a fake Chinese meaning.
- Sentence context is used for lightweight POS disambiguation:
  - `une tâche difficile` → noun
  - `je tâche de comprendre` → `tâcher`
  - `il est content` → `être`
  - `à l'est` → noun `est`
  - `son père` → possessive determiner
  - `le son` → noun “声音”
  - `il livre` → `livrer`
  - `un livre` → noun “书”
- Common irregular verb forms are reverse-resolved offline (`pris → prendre`, `dit → dire`, `fait → faire`, etc.).
- Conservative regular `-er` reverse candidates are only accepted when the lemma exists in lexical data.
- Full dictionary now has dedicated **词形** and **其他可能** sections.
- Related words no longer duplicate multi-word fixed expressions.
- Fixed expressions receive a small learning-oriented ranking so useful verb idioms are not automatically buried behind short technical noun phrases.

## Architecture

The new schema has independent `lexeme` and `form_analysis` tables and already contains `frequency` fields. This leaves a clean path for later build-time overlays from Lexique 3.83 and Morphalou 3.1 without changing the Android UI or lookup API again.

## Important limitation

V4.6 implements the new resolver and normalized morphology structure using the data already shipped with Lirelia plus a tiny ambiguity fallback set. The full Lexique 3.83 / Morphalou 3.1 frequency-and-coverage overlay is **not bundled yet**. It is the next data-quality step, not required for this structural fix.
