# Lirelia Mobile V3.21 — Reader Bugfix & Identity Update

This release focuses on stability and the real reading workflow rather than adding new modules.

## Main changes
- Renamed the launcher/app surface to **Lirelia** while keeping the same `applicationId` so existing app data can upgrade in place.
- Added the new Lirelia open-book launcher icon.
- Replaced the long-press `Dialog` with a true Compose `Popup`: no full-screen dim layer.
- Tapping a highlight color now applies it immediately and closes the popup so the result is visible.
- Dictionary clear action now removes that exact lexical item's annotations across all books plus its vocabulary state, while leaving sentence/phrase notes untouched.
- Added core offline entries for common French pronouns/function words such as `on`, `je`, `tu`, `il`, `elle`, `nous`, `vous`, `en`, and `y`.
- Dictionary center now accepts words, phrases, and full sentences. Exact offline phrase hits win; otherwise it shows offline lexical gloss immediately and enriches it with normal sentence translation asynchronously when available.
- Multi-word dictionary queries use a smaller readable heading instead of rendering a whole sentence as a giant headword.

Internal preference/database names and backup format identifiers remain compatible with previous Language Reader versions.
