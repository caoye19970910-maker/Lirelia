# V4.2 Readium Stabilization / No Ollama

This release addresses the V4.1 audit findings.

## Fixed

1. Removed the Ollama client, settings UI and translation path.
2. Moved Readium EPUB annotations into `LearningStore` / `learning.db`.
3. Added one-time migration from the temporary V4.0/V4.1 Readium SharedPreferences annotation store.
4. Added one-time migration of legacy paragraph highlights/notes into Readium Locators using EPUB search + nearest progression matching.
5. Added Locator-backed EPUB bookmarks and one-time migration of legacy paragraph bookmarks.
6. Added Readium progress to the normal backup preferences list.
7. Restored EPUB reading-time and reading-profile integration.
8. Restored keep-screen-on, landscape two-page, volume-key page turns, tap-zone actions, auto-scroll, reading ruler and blue-light overlay.
9. Made reader chrome, sheets, translation dock and selection tools theme-aware for dark reading.
10. Fixed sentence detection on word tap to use the actual DOM character offset.
11. Made WikDict replacement transactional enough to retain the previous known-good DB if the new verified file cannot be moved into place.
12. Added a working `gradle-wrapper.jar` entry to the project.

## Intentionally unchanged

- Application id remains `com.cy.languagereader.mobile`.
- PDF/TXT reader implementations are unchanged.
- Existing bundled French dictionary remains the primary lexicon.
- Network sentence translation remains Google endpoint first, MyMemory fallback, with cached results; safe mode disables network translation.
