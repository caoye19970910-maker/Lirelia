# V3.15 Dictionary Coverage

The release targets missing-word failures observed in real reading sessions.

## Confirmed examples addressed

- `triste` → offline supplement
- `baissées` → stronger morphology / `baisser`
- `inflexible` → offline supplement
- `intraitable` → offline supplement

## Behavior

A miss no longer immediately becomes “not found”. The app exhausts local lexical options first, then reuses a cached word meaning if available, and only then (when Safe Mode is disabled) performs the same lightweight free network translation already used by sentence translation. Ollama is explicitly disabled for this fallback.
