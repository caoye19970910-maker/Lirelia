# V4.0 — Readium Translation First

## Reader architecture

`EPUB file -> Readium AssetRetriever -> PublicationOpener -> EpubNavigatorFragment`

Compose owns only the interaction shell: translation dock, selection toolbar, reader chrome, typography and TOC. The EPUB publication itself remains a stable navigator surface below those layers.

## Translation path

1. Tap a French word in the EPUB WebView.
2. A tiny injected click bridge extracts the word plus nearby sentence.
3. Lirelia's offline dictionary returns lexical meaning first.
4. SentenceTranslationManager enriches the same dock with whole-sentence Chinese translation.
5. Full dictionary is secondary and opens only when requested.

## Selection/highlight path

Long press remains native Readium text selection, but the Android system ActionMode menu is suppressed. Lirelia reads `currentSelection()`, places a sibling Compose toolbar near the selection rect, and stores highlights as Readium Locators. `applyDecorations()` renders them back into the publication.

## Dictionary extension

Dictionary Center can optionally download the CC0 French-Chinese Wikidata mapping list from `open-dict-data/wikidict-zh`, build a private indexed SQLite database, verify it, then atomically replace the prior extension. It is queried only after the full bundled dictionary and Lirelia core fallback miss.
